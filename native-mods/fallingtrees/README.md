# Panda's Falling Trees for Horizon

Trees fall when their base is chopped with an axe.

A port of [Panda's Falling Trees](https://github.com/PandaMods-Dev/Pandas-Falling-Trees) 0.13.2 by The Panda Oliver to Horizon 26.3.

## Features
- Chopping a tree log with an axe fells connected logs (up to 256), attached vines/cocoa/bee nests, and non-persistent leaves within radius 10.
- All drops spawn cleanly at the base/stump.
- Held axe receives durability wear per extra log felled.
- Sneaking (Shift / touch sneak button) allows chopping a single log (vanilla behavior preserved).
- Options menu under `Options > Mods > Falling Trees` (Toggle ON/OFF, Break Leaves, Wear Axe).
