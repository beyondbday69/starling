# Sound Physics Remastered (Horizon Rust port)

A Rust port of [Sound Physics Remastered](https://github.com/henkelmax/Sound-Physics-Remastered) (henkelmax, GPL-3.0-only) for the Horizon client.

## Features
- Direct-path acoustic occlusion raymarching: blocks absorb and muffle sound.
- Per-block acoustic materials: stone echoes, wood dampens, wool absorbs.
- Underwater acoustic muffling and low-pass filtering.
- Distance attenuation falloff.
- Raytraced reverberation estimation for enclosed caves and rooms.
- Configurable settings in `Options > Mods > Sound Physics Remastered`.
